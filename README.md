# Proyecto Base de Datos II: Sistema de Gestión Hotelera

### Descripción del Proyecto

Este proyecto se centra en el diseño, implementación y optimización de un Sistema de Base de Datos Relacional para la gestión integral de un hotel. 

El sistema maneja todos los aspectos operativos, incluyendo la administración de habitaciones, clientes, reservas, servicios y facturación.



El enfoque principal de la segunda fase  fue la construcción de un sistema automatizado y seguro, utilizando características avanzadas del DBMS para garantizar la integridad y la eficiencia de los datos.
